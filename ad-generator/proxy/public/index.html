Fable 5 proxy

Verbatim passthrough to the Anthropic Messages API for the Atelier Console ad generator. Fallback (Fable 5 → Opus 4.8) is handled server-side by Anthropic.

  • POST /anthropic — forwards to api.anthropic.com/v1/messages
  • GET /health — the app's "Test proxy" ping

See the repo README for configuration and deployment.
